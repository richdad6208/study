### SSOT 준수

- **Single Source Of Truth**: 어떠한 데이터도 단 하나의 출처에서 생성하고 수정해야 한다는 원칙

```javascript
const UserEmail = ({ initialEmail }) => {
  /** 2개의 출처 */
  const [email, setEmail] = useState(initialEmail);

  /** 동기화하는 것은 개발자가 추적하기 어려운 오류가 발생할 수 있다. */
  useEffect(() => {
    setEmail(initialEmail);
  }, [initalEmail]);

  return <input value={email} onChange />;
};
```

### 상태 끌어올리기

- 상위 컴포넌트에서 상태를 관리하도록 해줌

```javascript
const UserEmail = ({ email, setEmail }) => {
  /** 1개의 상태 */

  const onChangeEmail = (event: React.ChangeEvent<HTMLInputElement>) => {
    setEmail(event.target.value);
  };

  return <input value={email} onChange={onChangeEmail} />;
};
```
