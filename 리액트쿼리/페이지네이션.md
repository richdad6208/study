### 페이지네이션 UX 향상

- useEffect를 활용하여, 1page 로드시, preFetch 진행한다

```javascript
useEffect(() => {
  queryClient.prefetchQuery({
    queryKey: ["users", String(page + 1)],
    queryFn: async (): Promise<PageResponse<User>> => {
      return fetch(
        ENV.SERVER_URL + API_URL.CATEGORY + `?page=${page + 1}&per_page=2`,
        fetchHeader
      )
        .then(async (res) => await res.json())
        .then((res) => res);
    },
  });
}, [page, queryClient]);
```

- placeholderData: keepPreviousData(리액트쿼리 유틸함수)를 이용하여 Pending 상태일 때, 이전 데이터를 유지

```javascript
/** Data */
const { data } = useQuery({
  queryKey: ["users", String(page)],
  queryFn: async (): Promise<PageResponse<User>> => {
    return fetch(
      ENV.SERVER_URL + API_URL.CATEGORY + `?page=${page}&per_page=2`,
      fetchHeader
    )
      .then(async (res) => await res.json())
      .then((res) => res);
  },
  placeholderData: keepPreviousData,
});
```
